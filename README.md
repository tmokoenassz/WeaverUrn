# WeaverUrn

WeaverUrn is a containerized, event-driven data orchestration platform that enables seamless auto-scaling data-integration frameworks.

With WeaverUrn, you get a lightweight tool that stays out of your way.

**What you get**

- WeaverUrn is a containerized, event-driven
- data orchestration platform that enables
- seamless auto-scaling data-integration frameworks

## Technology Stack

- rust
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/WeaverUrn.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
